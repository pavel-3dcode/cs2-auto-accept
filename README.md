# CS2 Auto Accept

Учебная утилита для автоматического принятия матчей в Counter-Strike 2. Ищет заданный цвет в области экрана и выполняет клик.

**Стек:** Python · Tkinter · PyAutoGUI · Pillow.

## Возможности

- Включение и остановка поиска через графический интерфейс.
- Настройка цвета и области поиска.
- Журнал событий и ошибок.
- Автоматическая остановка после одного клика.

## Запуск

Windows, Python 3.11. Выполни в папке проекта:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe accept.py
```

## Использование

В начале `accept.py` настрой `TARGET_COLOR` — RGB-цвет кнопки и `SEARCH_AREA` — область `(x, y, ширина, высота)` на основном экране.

Открой игру, оставь область поиска видимой и нажми **Auto Accept Off**, чтобы включить поиск. После клика он остановится. Повторное нажатие кнопки останавливает поиск вручную.

## Тесты

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## Статус

Прототип: работа в CS2 не проверена. Поиск основан на точном совпадении одного цвета, поэтому возможны ложные клики. При изменении разрешения или интерфейса потребуется перенастройка.
