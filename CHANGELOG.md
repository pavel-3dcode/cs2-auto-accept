# Изменения при подготовке к GitHub

- Рабочая логика взята из исходного `derank.py` и перенесена в `accept.py`.
- Убрана дублирующая версия окна, в которой поиск был закомментирован.
- Исключены `.venv`, `.idea` и скомпилированные файлы из исходного архива.
- Добавлены README, зависимости, правила Git и тесты.
- Параметры поиска вынесены в начало файла, исходный цвет и область сохранены.
- Изменения виджетов выполняются в основном потоке через очередь сообщений.
- Убрана глобальная подмена `sys.stdout`.
- Повторный запуск недоступен до завершения предыдущего потока.
- Ошибки захвата и PyAutoGUI fail-safe выводятся в журнал.
- Область поиска проверяется относительно размера основного экрана.
- **Поведение изменено:** после первого клика поиск останавливается. В исходной версии он продолжался и мог кликать повторно каждую секунду.
- Закрытие окна ожидает завершения текущего прохода фонового потока.

Проверка с настоящим окном CS2 и графическим окружением Windows не проводилась.
